## 🌟 專案簡介 (Project Overview)
**嶼光珈琲 Lumière Isle Café** 是一座座落於蔚藍海岸線旁的沉浸式慢活咖啡廳。  
本專題結合商業設計系的視覺美學與 AI Agent 協同開發，打造兼具「顧客前台沉浸體驗」與「後台資料即時管理 (CRUD)」的現代化 Web 應用程式。

- 🌐 **官網入口**：`index.html`
- 📑 **15 頁期末成果簡報**：`presentation.html`
- 🛠️ **後台管理系統**：點擊網頁右下角浮動按鈕或導覽列「後台資料管理」進入

## 💎 核心功能亮點 (Key Features)

### 1. 顧客體驗前台 (Customer Facing)
- **品牌識別與故事**：原創幾何 Logo（結合海浪、晨曦日落與咖啡豆弧線）與大地色調美學系統。
- **今日命定咖啡推薦測驗 (Coffee Matchmaker)**：3 題式互動心理測驗，根據烘焙深度、口感與當下狀態演算推薦專屬單品，支援一鍵加入訂單。
- **精選菜單與線上點單**：5 大分類（手沖單品、義式咖啡、季節特調、手作甜點、輕食早午餐）、即時關鍵字過濾搜尋。
- **細緻客製化彈窗 (Modal)**：自由選擇冰溫（熱飲/正常冰/少冰/去冰）、甜度（無糖/微糖/半糖）與加價升級（Oatly 燕麥奶/追加濃縮）。
- **外帶購物車與結帳模擬**：滿額折扣試算、約定取餐時間、付款方式模擬與領取專屬取餐號碼。
- **線上座席預約系統**：內建日期防呆機制（限制今日起算）、固定營業時段與座位區域偏好（海景窗邊、沉浸吧檯、戶外庭院、閱讀工作區）。

### 2. 後台資料管理系統 (Admin CRUD Dashboard - 🏆 期末加分關鍵)
- **菜單品項管理 (Create, Read, Update, Delete)**：
  - 新增全新咖啡或甜點品項（品名、分類、價格、標籤、特色描述）。
  - 編輯修改現有品項資料與價格。
  - **一鍵切換庫存狀態**：切換為「已售完 (Sold Out)」後，前台卡片即刻同步標記並鎖定點餐按鈕！
  - 刪除舊款品項。
- **顧客預約管理 (Reservation CRUD)**：
  - 即時瀏覽顧客線上預約名單、人數與特殊需求。
  - 即時維護訂位狀態（待確認、已確認、已入座、已取消）。
  - 支援手動廢棄或刪除測試預約。
- **首頁跑馬燈公告管理**：
  - 即時修改官網頂端促銷公告與營業時間。
- **展示資料重置工具**：
  - 一鍵恢復初始 12 筆菜單與示範預約，便於現場 Demo。

## 🛠️ 三處實際改善紀錄 (Mandatory Improvements)

1. **改善紀錄一【手機版響應式抽屜導航重構】**
   - **原本的問題**：在小螢幕（寬度 < 640px）瀏覽時，頂部導航連結擠在同一列造成文字重疊，菜單分類標籤過長產生橫向捲軸破版。
   - **改了什麼**：設計漢堡選單抽屜（Mobile Nav Drawer），菜單分類標籤採用 `overflow-x-auto` 支援橫向平滑滑動。
   - **怎麼確認**：以 Chrome DevTools 模擬 iPhone 14 (390px) 檢測，漢堡選單展開流暢，分類標籤滑動自如。

2. **改善紀錄二【線上訂位系統時段邏輯與防呆驗證】**
   - **原本的問題**：早期原型使用純文字輸入與開放日期選擇器，使用者可以選取過去日期，亦可預約半夜時段產生無效資料。
   - **改了什麼**：JavaScript 動態鎖定 `dateInput.min = today`，並將預約時段限制在營業時間（10:00 - 18:00）。
   - **怎麼確認**：在介面上測試選取昨日日期，呈現灰色不可點選；送出預約表單後即時產生 `#RES-xxxx` 憑證並寫入後台。

3. **改善紀錄三【後台 CRUD 與前台菜單庫存狀態即時雙向連動】**
   - **原本的問題**：初版後台管理修改品項或切換售完後，前台不會即時更新，需重新整理網頁，購物車也無法辨識售完品項。
   - **改了什麼**：重構全域 `state` 與 LocalStorage 監聽機制，後台切換售完時，前台對應品項即時掛上紅標並禁用按鈕。
   - **怎麼確認**：在後台將「耶加雪菲」標記為「已售完」，返回前台該品項立即變灰並顯示「已售完 Sold Out」，無法加入購物車。

## 🚀 部署上線指引 (Vercel Deployment)
1. 在 GitHub 上建立一個新的 Public Repository（例如 `lumiere-isle-cafe`）。
2. 將本專案推送至 GitHub 主分支：
   ```bash
   git remote add origin https://github.com/<your-username>/lumiere-isle-cafe.git
   git branch -M main
   git push -u origin main
   ```
3. 登入 [Vercel](https://vercel.com/)，點擊「Add New Project」並匯入該專案庫。
4. Framework Preset 選擇「Other」，點擊「Deploy」即可免費取得公開上線網址！
